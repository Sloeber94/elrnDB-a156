Applies to: all engines; all production periods

When the steering is operated irregular steering which does not respond to the action of the steering wheel is noticeable

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Preliminarily check the tyre inflation pressure

Visually inspect the power assisted steering fluid level in the reservoir

Continue to Step 1

Pressure not correct

Restore the tyre inflation pressure

Power assisted steering fluid level too low

Restore the correct level, if there are leaks,

See table X30 POWER ASSISTED STEERING SYSTEM FLUID LEAKS

1

WHEEL GEOMETRY CHECK

All OK

Problems met

Operation

Check the vehicle wheel geometry and front wheel angles, Op. 4450A10 front wheel geometry - check using optical equipment - includes front wheel tow-in adjustment if necessary

Continue to Step 2

Wheel geometry not correct

Replace the suspension springs Op. 4410A10 l/h or r/h front suspension spring/damper unit (one) - r+r - check wheel geometry separately if necessary

Angles not correct

Restore the correct angles, where possible

2

REAR WHEEL GEOMETRY CHECK

All OK

Problems met

Operation

Check the vehicle geometry and rear wheel angles Op. 4450A40 rear wheel geometry - check using optical equipment

Continue to Step 3

Wheel geometry not correct

Replace the suspension springs Op. 4420A10 l/h or r/h rear suspension spring/damper unit (one) r+r

Angles not correct

Restore the correct angles, where possible

3

STEERING COLUMN BEARINGS CHECK

All OK

Problems met

Operation

Check the condition and efficiency of the steering column support bearings

Continue to Step 4

Bearings worn or damaged

Replace the bearings concerned Op. 4110A34

4

STEERING BOX CHECK

All OK

Problems met

Operation

Check that the steering box is working properly: there should not be excessive "power assistance"

Continue to Step 5

Steering box not properly set

Replace the steering box Op. 4130A10 power steering box - r+r - check tow-in if necessary separately - includes bleeding

5

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

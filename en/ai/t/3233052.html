Applies to: all engines; all production periods

When the stalk unit collar is operated with the key turned on, the dipped headlamps do not work.

Results of the tests

1

CHECK INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 2

Bulbs damaged

Replace bulbs

Light unit faulty

Repair or change the front light unit Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

2

CHECK THE DIPPED HEADLAMP ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • right and left dipped headlamp fuses
  • dipped headlamp maintenance relay
  • connection between stalk unit, relay and junction unit
  • connection between junction unit and bulbs
  • bulb earth

( See E2011 DIPPED HEADLAMPS ).

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

3

STEERING COLUMN SWITCH UNIT CHECK

All OK

Problems met

Operation

Check the stalk unit is working properly: in particular, check the side light switch see DESCRIPTION AND OPERATION: 5550A stalk unit

Continue to Step 4

Stalk unit not working properly

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

4

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

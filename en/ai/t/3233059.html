Applies to: all engines; all production periods

The fog lamps do not come on when the switch located on the central console is operated with the side lights on.

Results of the tests

1

CHECK INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and lamps

Continue to Step 2

Bulbs damaged

Replace bulbs

Lamp defective

Repair or replace the fog lamp Op. 5540D14 l/h or r/h fog lamp bulb (one) - r+r

2

CHECK FOG LAMP ELECTRIC CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • fog lamp fuse
  • fog lights relay.
  • services control unit supply
  • connections between relay and service control unit
  • connection between relay and bulb
  • connections between service control unit and fog lamp switch
  • relay earth and bulbs
  • fog lamp switch earth

( See E2030 FOG LIGHTS ).

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections (

3

SERVICES CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the services control unit is working properly, in particular the fog lamp control function see DESCRIPTION AND OPERATION: 5505 ELECTRICAL CIRCUIT FOR INSTRUMENTS/INDICATORS

Continue to Step 4

Control unit not working

Replace the services control unit Op. 5505A18 multi-function control unit - r r

4

CHECK FOG LAMP SWITCH

All OK

Problems met

Operation

Check the operation of the fog lamp switch

( See E2030 FOG LIGHTS ).

Continue to Step 5

Fog lamp switch faulty

Renew or replace the fog lamp switch Op. 5540D18 fog lamp switch - r+r

5

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

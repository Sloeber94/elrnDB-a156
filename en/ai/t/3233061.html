Applies to: all engines; all production periods

With the ignition turned ON, the light check device does not reveal any operating faults in the side lights, brake lights or rear fog lights - despite the fact that they are not working - and the light failure warning light is not turned on.

Results of the tests

1

CHECKING CHECK DEVIC

All OK

Problems met

Operation

Check the light check device inside the rev counter is working properly: see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

Continue to Step 2

Light check device not working properly

Replace the rev counter Op. 5560B03 rev counter - r r

2

CHECKING LIGHT CHECK ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • lighting fuses (right and left branches)
  • connections between rev counter and junction unit
  • rev counter supply
  • rev counter earth

( See E2010 SIDE LIGHTS / NO. PLATE LIGHTS ).

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections

3

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

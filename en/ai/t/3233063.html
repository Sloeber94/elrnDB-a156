The interior timed lights can be controlled by hand but the timing function does not work or is irregular.

Results of the tests

1

CHECKING TIMED LIGHTING CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • services control unit supply
  • Connections between service control unit and door contacts
  • connections between service control unit and lights
  • service control unit earth

( See E2510 COURTESY LIGHTS ).

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore connections

2

SERVICES CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the services control unit is working properly, in particular the timed lighting function: see DESCRIPTION AND OPERATION: 5505 ELECTRICAL CIRCUIT FOR INSTRUMENTS/INDICATORS

Continue to Step 3

Control unit not working

Replace the services control unit Op. 5505A18 multi-function control unit - r r

3

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

The interior timed lights can be controlled by hand but the timing function does not work or is irregular.

Results of the tests

1

CHECKING TIMED LIGHTING CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • services control unit supply
  • connections between services control unit and contacts between the doors
  • connections between service control unit and lights
  • service control unit earth ( See E2510 COURTESY LIGHTS )

Continue to Step 2

Component defective

Replace the component involved (if it is a fuse, search for the cause of the problem)

Connections broken

Restore connections

2

COURTESY LIGHTS SUPPLY CHECK

All OK

Problems met

Operation

Check, in order:

  • battery link
  • junction unit
  • right rear earth

Continue to Step 3

Damaged components

Replace the component involved

3

CENTRAL LOCKING MOTORS CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the door lock geared motor is working properly

Continue to Step 4

Geared motor damaged

Replace the geared motor

4

SERVICES CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the services control unit is working properly

Continue to Step 5

Control unit damaged

Replace the services control unit ( Op. 5505A18 multi-function control unit - r r )

5

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

J01 WINDSCREEN/REARSCREEN WASHERS NOT WORKING

Applies to: all engines; all production periods

With the igntion key in the ON position, when the lever on the right of the steering wheel is operated, the windscreen wash/wipe should work properly.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check that the windscreen wipers and washers are not working

Continue to Step 1

Only the windscreen wipers are not working

See table J02 WINDSCREEN WIPERS NOT WORKING

The windscreen washer is not working

See table J03 SCREEN WASHER NOT WORKING

1

WINDSCREEN WIPER ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • windscreen wiper fuse
  • starting inhibitor relay
  • steering column switch unit supply

( See E3020 WINDSCREEN WASH/WIPE ).

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore the connections

2

STEERING COLUMN SWITCH UNIT CHECK

All OK

Problems met

Operation

Check that the steering column switch unit is working properly: in particular, the resistances inside it which determine the intermittent operation of the windscreen wiper: see DESCRIPTION AND OPERATION: 5550A stalk unit

Continue to Step 3

Intermittent device not working properly

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

3

CHECK CORRECT OPERATION

Check that the fault is no longer present

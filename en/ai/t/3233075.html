Applies to: all engines; all production periods

With the ignition key ON, the speedometer does not work or works irregularly

Results of the tests

1

CHECK SPEEDOMETER ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • connection between speedometer and ABS control unit
  • service fuse
  • ignition-operated service fuse
  • the speedometer supply
  • speedometer earth

( See E4021 SPEEDOMETER ).

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections (

2

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there are no faults in the ABS control unit. In particular, check the speedometer signal is sent properly by the control unit. The signal is pulse-type: two pulses per wheel revolution

Continue to Step 3

Signal not sent

Check the ABS control unit and replace if necessary Op. 3340A12 A'B.S. system. - electronic and hydraulic CONTROL UNIT R.R.

3

SPEEDOMETER CHECK

All OK

Problems met

Operation

Check the operation of the speedometer: see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

Continue to Step 4

Instrument not working

Replace the speedometer Op. 5560B02

4

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

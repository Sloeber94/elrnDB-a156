With the key turned ON, the mileometer works normally but the trip counter cannot be reset

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check operation of the mileometer

CHECK THE RESET BUTTON

All OK

Problems met

Operation

Check operation of the mileometer reset button

( See E4021 SPEEDOMETER ).

Continue to Step 2

Reset button faulty

Reset or change the reset button Op. 5540C18 headlamp/light cluster alignment correction motor switch - r+r

2

CHECKING RESET ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • connection between speedometer and mileometer reset control
  • trip counter reset button earth

Connection broken

Restore connection

Operation

Check speedometer operation, and milometer reset operation in particular see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

note that the trip counter is reset when the battery is disconnected

Replace the speedometer Op. 5560B02

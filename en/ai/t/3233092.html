Applies to: all engines; all production periods

During starting, the CODE warning light does not come on (it should come on for 0.7 seconds to indicate that the initial control unit test has been carried out, and it should then go out)

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there is regular dialogue with the CODE control unit

Continue to Step 2

Lack of dialogue with the control unit

Restore:

  • the connection between the CODE control unit and the diagnostic connector
  • the supply for the CODE control unit.
  • ( See E7010 CODE ).

An error is detected in the control unit

Continue according to the instructions for the diagnostic equipment

2

CODE WARNING LIGHT CHECK

All OK

Problems met

Operation

Using the diagnostic equipment (Examiner or other instruments), carry out the active diagnosis for the CODE warning light

Continue to Step 3

Connections not correct

Restore the connections

3

CHECK CONTROL CHECK

All OK

Problems met

Operation

Check the operation of the check control instrument see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

Continue to Step 4

Instrument not working

Replace the check control instrument Op. 5560C60 anomaly display - r+r

4

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

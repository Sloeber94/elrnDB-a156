Applies to: all engines; all production periods

During starting, the i.e. failure and the CODE warning lights come on and remain on

If both the i.e. failure and the CODE warning lights remain on simultaneously, this means that there has been no dialogue between the two control units to recognize the key that has been inserted and therefore starting will not be enabled.

Applies to: all engines; all production periods

During starting, the ABS failure warning light comes on and remains on for more than 4 seconds.

(after carrying out the initial control unit test, the warning light should go out, ...)

Under these circumstances it is possible that the wheels may lock when the brakes are operated sharply because the ABS system is temporarily deactivated.

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check:

  • that there are no faults in the ABS control unit
  • plausibility of all the parameters

Continue to Step 2

An error is detected in the control unit

Continue according to the instructions for the diagnostic equipment

Lack of dialogue with the control unit

Restore the connection between the ABS control unit and the diagnostic connector

( See E7020 ABS ).

2

CHECK INSTRUMENT SUPPLY CHECK

All OK

Problems met

Operation

The ABS warning light is equipped with an interior control circuit that ensures the warning light is properly connected to the control unit.

Check the connection between ABs control unit and check control instrument.

( See E7020 ABS ).

Continue to Step 3

Connections not correct

Restore the connections

Instrument not working

Replace the check control instrument Op. 5560C60 anomaly display - r+r

3

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

K63 HANDBRAKE WARNING LIGHT OFF / (DO NOT CARRY OUT INITIAL TEST)

Applies to: all engines; all production periods

On starting, the "handbrake" warning light does not come on (it should come on for 2 seconds to indicate the initial test of the control unit, and then go out)

The "low brake fluid" and "handbrake on" warning light, it also indicates an EBD function fault if it comes on at the same time as the ABS warning light

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there is a regular dialogue with the ABS control unit

Continue to Step 2

Lack of dialogue with the control unit

Restore:

  • the connection between the ABS control unit and the diagnostic connector
  • the ABS control unit supply

( See E7020 ABS ).

An error is detected in the control unit

Continue according to the instructions for the diagnostic equipment

2

CHECKING CHECK CONTROL POWER SUPPLY

All OK

Problems met

Operation

Check, in order:

  • connection between ABs control unit and check control instrument.
  • supply to check control instrument

( See E4022 CENTRE INSTRUMENT (CHECK) ).

Continue to Step 3

Connections not correct

Restore the connections

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

3

CHECK CONTROL CHECK

All OK

Problems met

Operation

Check the operation of the check control instrument see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

Continue to Step 4

Instrument not working

Replace the check control instrument Op. 5560C60 anomaly display - r+r

4

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

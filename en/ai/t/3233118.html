M01 ELECTRIC FRONT WINDOWS / NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position, when the buttons on the doors are operated, the electric front windows do not work at all

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check that there are no obstacles preventing the travel of the window

Check that the electric windows fail to work in all conditions (manual and/or automatic operation)

Continue to Step 1

Presence of obstacles

Restore the correct mechanical operation of the window - up/down

The electric window operate manually (the window goes up/down with the button pressed), but not automatically

See table M02 ELECTRIC FRONT WINDOWS / NOT WORKING IN AUTOMATIC MODE

1

ELECTRIC WINDOW SWITCHES CHECK

All OK

Problems met

Operation

Check the operation of the electric front window switched

Continue to Step 2

Switch faulty

Replace the electric window switch Op. 7005M10 driver's side front side door glass control switch (one) r r

2

ELECTRIC WINDOWS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • electric windows fuse
  • switches supply and earth
  • services control unit supply
  • connection between services control unit and switched
  • connection between services control unit and electric windows motors.

( See E3050 ELECTRIC FRONT WINDOWS ).

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore the connections

3

SERVICES CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the services control unit is working properly, in particular the electric front windows control function see DESCRIPTION AND OPERATION: 5505 ELECTRICAL CIRCUIT FOR INSTRUMENTS/INDICATORS

Continue to Step 4

Control unit not working

Replace the services control unit Op. 5505A18 multi-function control unit - r r

4

ELECTRIC WINDOW MOTORS CHECK

All OK

Problems met

Operation

Check the operation of the electric window motors

Continue to Step 5

Electric window motor faulty

Replace the electric window motor Op. 7005M21 front side door electrically operated window - r r

5

ELECTRIC WINDOWS DEVICE CHECK

All OK

Problems met

Operation

Check the operation of the mechanical part of the electric windows control device and that it is correctly fixed

Continue to Step 6

Electric window device not correctly fixed or adjusted

Restore the operation of the electric window device Op. 7005M25 front side door electrically operated window mechanism chech position and fastening

Electric window device faulty

Replace the electric window device Op. 7005M21 front side door electrically operated window - r r

6

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

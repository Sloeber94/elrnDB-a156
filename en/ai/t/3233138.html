P02 REAR DOOR CLOSING DEFECTIVE

Applies to: all engines; all production periods

When the central door locking is operated with the key or remote control, or from inside using the safety knob, one of the rear doors does not shut properly.

If a door does not shut properly, when the central locking is operated, the four dooes may close and then reopen after a few moments

Results of the tests

1

CHECK DOOR LOCK STRIKER

All OK

Problems met

Operation

Check that the lock striker is fixed correctly

Continue to Step 2

Striker incorrectly secured

Refix the striker correctly Op. 7010A10 rear side door - adjust striker and adapt seal if necessary

2

CHECK KNOB OPERATION

All OK

Problems met

Operation

Check that the door opens / closes correctly when the safety knob is operated

Continue to Step 3

Faults in control linkage

Re-engage the linkage correctly on the intermediate linkage and lock Op. 7010C67 rear side door safety catch link-r r and Op. 7010C69 rear door catch return - r r

Lock not fixed correctly

Refit the lock correctly on the door Op. 7010N21 rear side door lock motor-lock assembly r r

3

CHECK OPERATION OF EXTERNAL HANDLE

All OK

Problems met

Operation

Check that the door opens / closes correctly when the external handle is operated

Continue to Step 4

Faults in external handle linkages

Re-engage the linkages correctly on the external handle and lock Op. 7010C65 handle link to lock - r r

Lock not fixed correctly

Refit the lock correctly on the door Op. 7010N21 rear side door lock motor-lock assembly r r

4

CHECK OPERATION OF INTERNAL HANDLE

All OK

Problems met

Operation

Check that the door opens / closes correctly when the internal handle is operated

Continue to Step 5

Faults in internal handle linkages

Re-engage the linkage correctly on the handle Op. 7010C55 rear side door interior opening return device (with handle) - r+r for repair or replacement

Faults in lock control

Re-engage the linkage correctly on the lock Op. 7010C51 rear side door inner catch return device - r+r for repair or replacement

Lock not fixed correctly

Refit the lock correctly on the door Op. 7010N21 rear side door lock motor-lock assembly r r

5

CHECK CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

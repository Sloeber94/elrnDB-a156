When the central door locking is operated with the key (or remote control) the doors do not open / close at all.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check that the battery voltage is over 9 V

Continue to Step 1

Battery voltage below 9 V: in these conditions the door locks are not supplied by the control unit

Restore the correct battery voltage

1

CHECK OPERATION OF INDIVIDUAL DOORS

All OK

Problems met

Operation

Check that, when the door lock/unlock is operated, none of the locks is activated

Continue to Step 2

Fault in one of the front locks

Check and if necessary replace the front door lock motors Op. 7005N21 front side door lock motor-lock assembley-r r

Fault in one of the rear locks

Check and if necessary replace the rear door lock motors Op. 7010N21 rear side door lock motor-lock assembly r r

Faulty connection between services control unit and one of the locks

door lock motors See E3040 CENTRAL LOCKING

2

CENTRAL LOCKING ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • central locking fuse, located in junction unit
  • connection between junction unit and services unit
  • services control unit supply
  • correct operation of services control unit

See E3040 CENTRAL LOCKING

Continue to Step 3

Connections not correct

Restore connections

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Control unit not working

Replace the services control unit Op. 5505A18 multi-function control unit - r r

3

When the central door locking is operated with the key (or remote control) the doors do not open / close at all.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check that the battery voltage is over 9 V

Continue to Step 1

Battery voltage below 9 V (in this case the locks are not supplied by the control unit).

Restore the correct battery voltage

1

DOOR OPERATION CHECK

All OK

Problems met

Operation

Check that the doors lock/unlock properly using the key.

Continue to Step 2

Fault in the front locks

Check and if necessary replace the front door lock motors ( Op. 7005N21 front side door lock motor-lock assembley-r r )

Fault in the rear locks

Check and if necessary replace the rear door lock motors ( Op. 7005N21 front side door lock motor-lock assembley-r r )

Lack of continuity between control unit and door lock geared motors

Restore the continuity between the control unit and the door lock geared motor, if necessary, replacing the wiring.

2

CENTRAL LOCKING ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • central locking fuse located in services control unit
  • connection between services control unit and junction unit ( See E3040 CENTRAL LOCKING )

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connection damaged

Restore connections

3

INTEGRATED ELECTRIC WINDOWS CENTRAL LOCKING ELECTRONIC CONTROL UNIT

All OK

Problems met

Operation

Check that the integrated electric windows central locking is working properly

Continue to Step 4

Control unit not working

Replace the integrated electric windows central locking control unit ( Op. 5505A18 multi-function control unit - r r )

4

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

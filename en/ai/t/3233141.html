When the central locking is operated using the remote control the doors do not open / close at all.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check the charge of the remote control incorporated in the key

Check that the central locking is working properly using the key

Continue to Step 1

Remote control battery run down

Replace battery

Central locking mechanical fault

See table P10 CENTRAL LOCKING / NOT WORKING

1

REMOTE CONTROL RECEIVER CHECK

All OK

Problems met

Operation

Check the supply, earth and connections with the integrated electric windows central locking control unit

Continue to Step 2

Connections damaged

Restore the correct connections

Component defective

Replace the alarm remote control receiver

2

CENTRAL LOCKING ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • central locking fuse, located in service control unit
  • connection between service control unit and junction unit
  • control unit supply ( See E3040 CENTRAL LOCKING )

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connection damaged

Restore connections

3

INTEGRATED ELECTRIC WINDOWS CENTRAL LOCKING ELECTRONIC CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the integrated electric windows central locking control unit is working properly

Continue to Step 4

Control unit not working

Replace integrated electric windows central locking control unit ( Op. 5505A18 multi-function control unit - r r )

4

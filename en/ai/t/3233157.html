Applies to: all engines; all production periods

With the engine running, when the various gears are engaged, there is a noise during take-off: the noise varies as the speed varies

Results of the tests

1

CHECKING THE GEAR SET

All OK

Problems met

Operation

Check the crown wheel and pinion reduction gear (see OVERHAULING GEARBOXES Assembly 2110D)

In particular:

  • it should not be worn or damaged
  • there should not be excessive clearance
  • the ring gear fixings should not be slack

Continue to Step 2

Reduction gear damaged

Restore the clearance or, if necessary, replace the reduction gear

2

CHECKING PLANET CARRIER

All OK

Problems met

Operation

Check the wear of the planet carrier or the housing in the differential case (see OVERHAULING GEARBOXES Assembly 2110D)

Continue to Step 3

Differential case worn

Replace the differential casing

3

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'

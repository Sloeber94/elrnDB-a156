Applies to: all engines; all production periods

Description

This is a dot matrix display with electronic management/calculation and operation and a buzzer for warning signals.

The selection/confirmation controls for the functions displayed by the infocenter are located near the climate control system controls and consist of 3 buttons (+/-/INFO); the SET function control button is located on the left steering column switch unit lever.

Functions displayed:

  • Engine oil level (histrograms)
  • Service messages
  • Speed limit (acoustic warning as well)
  • Date
  • Fault signal repetition
  • Outside temperature
  • Lighting adjustment through histrograms
  • Language selection
  • Doors check
  • Operation of inertia switch
  • Engine oil temperature (GTA only)
  • Trip computer

The instrument works with the ignition switched ON.

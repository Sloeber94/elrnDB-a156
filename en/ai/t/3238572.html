Applies to: all engines; all production periods

It is not possible to order a single lock barrel or to order barrels simply by using a part code.

When ordering barrels, observe the special procedure set out in 5580E anti-theft device .

Applies to: all engines; all production periods

Removing

Refitting

1. Keep handle button (1a) pressed in and remove the key barrel retaining clip (1b).

2. Take out the key barrel (the barrel is part of the button).

Applies to: all engines; all production periods

Refitting

Removing

Check that the barrel is undamaged.

1. Insert the key barrel retaining clip.

2. Fit the key barrel (2b) and engage notches (2b) with the retaining clip

Applies to: all engines; all production periods

Check that the barrel and the lock control mechanism are working properly.

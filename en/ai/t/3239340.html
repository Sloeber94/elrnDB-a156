Applies to: all engines; production: da 02/01 a 02/02; only with equipment: Station Wagon

Functional description

When a special button on the key is operated, a boot opening signal is sent to remote control receiver M35, which sends an earth signal to boot opening relay J56 that in turn supplies boot lock motor N57 via a line protected by fuse F6 of supplementary fuse box B98 C.
